MikroTik

Halaman ini disiapkan. Data belum diunggah.

Data yang dibutuhkan

  • Log router (System → Logs, atau hasil syslog ke server) dengan kolom waktu, topik, dan pesan.
  • Login ke router: akun, IP asal, berhasil atau gagal (topik system, account).
  • Firewall drop/reject bila logging diaktifkan: IP sumber, tujuan, port.
  • Perubahan konfigurasi oleh akun admin.

Rencana tampilan: login gagal ke router, IP sumber teratas yang di-drop, dan riwayat perubahan konfigurasi.

UniFi

Halaman ini disiapkan. Data belum diunggah.

Data yang dibutuhkan

  • Event/alarm dari UniFi Controller: waktu, jenis event, perangkat/AP, pesan.
  • Daftar client: MAC, hostname, SSID, AP, waktu pertama dan terakhir terlihat.
  • Login admin ke controller, bila tersedia.

Rencana tampilan: jumlah client per AP dan SSID, perangkat baru tak dikenal, dan disconnect berulang.

Fingerprint

Halaman ini disiapkan. Data belum diunggah.

Data yang dibutuhkan

  • Export absensi mesin fingerprint: ID karyawan, waktu scan, jenis (masuk/keluar), ID mesin.
  • Mapping ID karyawan ke email kantor, supaya bisa dicari dengan kolom email yang sama.
  • Daftar user terdaftar di mesin, untuk mencocokkan karyawan yang sudah keluar.

Rencana tampilan: rekap kehadiran, scan di luar jam kerja, dan karyawan keluar yang masih terdaftar di mesin.

Sumber: export Admin Console Google Workspace (log ditarik 23 Okt 2026, daftar akun ±28 Okt 2026) dan List of User Access. Periode review 1 Sep – 22 Okt 2026.
